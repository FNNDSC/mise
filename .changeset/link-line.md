A place's link is always in sight, and copying it says so. FILES shows the link under every path trail and RUNS shows it in the graph's corner (the selected node, else the feed), in full behind a LINK pill. A press copies it and the pill reads COPIED, or SELECT + COPY with the address selected where the browser has no clipboard. A row's LINK points that line at the row. The LINK pill on the RUNS rail is gone.
