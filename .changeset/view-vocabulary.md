Everything the RUNS graph shows can now be set from the console, and a desktop records all of it. New: `dag pulse|census|gravity on|off`, `dag draw spheres|stars`, `dag select <feed or job>` (the JUMP TO fly-to) and `dag enter <job>` (then ENTER NODE). `desktop show` now writes every graph setting and the feed or job on stage, so the script replays the same view anywhere.
