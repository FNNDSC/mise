= ARGUS keys
:toc:

GENERATED by `node scripts/keys-doc.mjs` from `DRAWER_CHORDS` in `apps/argus/src/console/argusLang.ts`. Do not edit by hand: `npm run lint:aegis` fails when this file and the table disagree.

Ctrl-B is the prefix: it opens the focused pane's drawer with keyboard focus on its first verb. With the drawer open, one key presses one of its capsules (the chords below); Tab walks the verbs, Enter fires, Esc closes. A key typed into a line is never a chord. `argus keys` prints this table in the console; the dashboard's HELP tile and `help pane` open it as a pane.

== The pane

[cols="1,4",options="header"]
|===
| Key | Does
| `%` | split right (tmux)
| `"` | split below (tmux)
| `h` | split left
| `j` | split below
| `k` | split above
| `l` | split right
| `H` | move this pane left
| `J` | move this pane below
| `K` | move this pane above
| `L` | move this pane right
| `m` | arm MOVE (then a direction)
| `z` | zoom (tmux), or double-click the pane's header
| `x` | close (tmux)
| `Space` | flip this pane's split: beside becomes above (tmux next layout)
| `!` | break this pane out: alone on stage, the rest a PANES card (tmux)
| `Ctrl-←↑↓→` | move the boundary beside this pane a step (tmux)
| `&` | close every pane on the stage (tmux kill-window)
|===

== Focus

[cols="1,4",options="header"]
|===
| Key | Does
| `o` | focus the next pane (tmux)
| `;` | focus the last pane (tmux)
| `q` | show every pane's @id on its bar (tmux)
| `r` | the keys into this pane's frame: Tab or ↑↓ walk its verbs, Enter presses, ← or Esc leaves
| `O` | focus the previous pane
| `←↑↓→` | focus the pane in that direction (tmux)
|===
