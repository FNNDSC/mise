MesloLGS NF (Regular, Bold)

These font files are the "MesloLGS NF" builds distributed with the
Powerlevel10k project (https://github.com/romkatv/powerlevel10k), vendored
here unmodified so the ARGUS console renders its full glyph set (powerline
separators, icons, box drawing) identically on every viewing machine.
