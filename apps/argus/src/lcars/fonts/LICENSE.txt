MesloLGS NF (Regular, Bold)

These font files are the "MesloLGS NF" builds distributed with the
Powerlevel10k project (https://github.com/romkatv/powerlevel10k), vendored
here unmodified so the ARGUS console renders its full glyph set (powerline
separators, icons, box drawing) identically on every viewing machine.

Provenance and licensing:

JetBrainsMono Nerd Font Mono (Regular, Bold)

The console's face: JetBrains Mono patched by Nerd Fonts (release v3.5.1, https://github.com/ryanoasis/nerd-fonts), the "Mono" build whose icons each take one cell, converted from TrueType to WOFF2 unmodified otherwise. JetBrains Mono is by JetBrains, under the SIL Open Font License 1.1 (JetBrainsMonoNerdFontMono-OFL.txt); the Nerd Fonts patching is MIT licensed.
